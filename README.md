# CollabAI

An AI-powered Real-Time Collaboration Platform built using Spring Boot, React, WebSocket, WebRTC, AI, and Cloud.

## Features

- JWT Authentication
- Real-Time Chat
- Video Calling
- Collaborative Code Editor
- AI Assistant
- Online Compiler
- File Sharing
- Cloud Storage

## Tech Stack

### Backend
- Java
- Spring Boot
- Spring Security
- MySQL

### Frontend
- React
- TypeScript
- Tailwind CSS

### Cloud
- AWS
